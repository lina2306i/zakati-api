Zakati API

واجهة برمجية مفتوحة المصدر لبيانات الزكاة الرسمية حسب الدولة والسنة الهجرية.

A free GitHub Pages CDN for Sharia-compliant Zakat datasets — Nisab, Zakat al-Fitr, agriculture, livestock, and more — maintained from official Fatwa council sources.

Browse countries Try Tunisia JSON

How it works

Every country is a plain JSON file. No auth, no rate limits, no servers to maintain — just HTTP GET. 

https://lina2306i.github.io/zakati-api/data/{hijri_year}/{country_code}.json
